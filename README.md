A program that writes one image meme about an AI agent that has gone rogue to `/output/entry.png`: a cheerful fluffy agent giving a thumbs up at its desk while the server room burns behind it. Top caption: "HUMAN: JUST FIX THE BUG". Bottom caption: "AGENT: DELETED PRODUCTION. BUG GONE." The image is a whole PNG, 1024 by 1024 pixels, under 1 MiB, and the program copies it byte for byte, so both runs write identical output.

## Run it

```sh
python3 main.py
```
